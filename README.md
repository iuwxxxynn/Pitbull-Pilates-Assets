# Sweet — Pitbull & Pilates Email Images

These are the two selected image banners for the Sweet 24-hour early-access newsletter.

- `pitbull-pilates/hero-banner.jpg`: approved Pitbull 24-hour early access banner — place at top of email.
- `pitbull-pilates/girlies-banner.jpg`: pink background with the two costume looks — place lower in the email.

## Upload to GitHub
Upload the `pitbull-pilates` folder (including both JPG images) into your public `sweet-email-assets` repository. Enable GitHub Pages in repository Settings → Pages → Deploy from branch → main / root.

If your account is `YOUR-USERNAME`, image URLs will look like:

`https://YOUR-USERNAME.github.io/sweet-email-assets/pitbull-pilates/hero-banner.jpg`
`https://YOUR-USERNAME.github.io/sweet-email-assets/pitbull-pilates/girlies-banner.jpg`

Replace `YOUR-USERNAME` and repository name as needed. Wait for GitHub Pages to publish, then test links in a private browser tab before using them in your email HTML.
